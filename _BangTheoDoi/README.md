# Bảng theo dõi nộp bài

File `TheoDoi_BaiN.xlsx` được GitHub tự tạo lại 30 phút một lần (xem `.github/workflows/bang-theo-doi.yml`).
Bảng chỉ có tình trạng nộp bài (Đúng hạn / Muộn / Quá hạn / Chưa nộp), **không có điểm**.
Bài đã gửi Pull Request nhưng chưa được gộp cũng được tính, có ghi chú "CHỜ CÔ GỘP".
File `.csv` cùng tên chỉ dùng để so sánh thay đổi.
